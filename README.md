# Ezequiel Ortiz — Frontend Developer Portfolio

Portafolio personal desarrollado para presentar mi perfil profesional, experiencia, tecnologías y proyectos como desarrollador Frontend. El sitio cuenta con una interfaz moderna, diseño adaptable y soporte para español e inglés.

**[Ver portafolio en línea](https://portfolio-ashen-ten-59.vercel.app)**

## Sobre el proyecto

Este proyecto reúne mi experiencia y trabajo en desarrollo de interfaces web, construcción de componentes reutilizables e integración de funcionalidades para aplicaciones web.

El portafolio fue desarrollado con React y TypeScript, utilizando Vite como herramienta de desarrollo y compilación.

## Características

* Diseño responsive para dispositivos móviles, tabletas y escritorio.
* Interfaz disponible en español e inglés.
* Navegación entre secciones y páginas individuales para cada proyecto.
* Galerías de capturas para mostrar las interfaces desarrolladas.
* Sección de experiencia profesional y tecnologías utilizadas.
* Audio ambiental opcional, activado únicamente mediante interacción del usuario.
* Enlaces a perfiles profesionales y medios de contacto.
* Soporte para navegación interna sin recargas innecesarias.
* Respeto por la preferencia de movimiento reducido del sistema.

## Proyectos destacados

### PocketPilot

Aplicación de finanzas personales orientada a la gestión y visualización de información financiera, con funcionalidades para organizar transacciones, presupuestos, metas y deudas.

### Expontánea SV

Sitio web para una floristería, con catálogo de productos, páginas de detalle y carrito de compras.

Aplicación web para un lubricentro, con servicios, autenticación de usuarios, agendamiento de citas y funcionalidades para clientes. El proyecto utiliza una arquitectura frontend y backend separada.

## Instalación y ejecución local

### Requisitos previos

* Node.js compatible con la versión de Vite utilizada por el proyecto.
* npm.
* Git.

### Clonar el repositorio

```bash
git clone https://github.com/Ezequiel906/portfolio.git
cd portfolio
```

### Instalar dependencias

```bash
npm install
```

### Iniciar el servidor de desarrollo

```bash
npm run dev
```

Vite mostrará en la terminal la dirección local para abrir el sitio en el navegador.

## Validación y compilación

Ejecutar ESLint para revisar el código:

```bash
npm run lint
```

Generar la compilación de producción:

```bash
npm run build
```

Previsualizar localmente la compilación generada:

```bash
npm run preview
```
